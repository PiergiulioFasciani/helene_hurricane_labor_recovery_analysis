# Historical archive

This directory preserves older snapshots and discontinued working material. The active pipeline never reads or runs these folders.

- `2026-11-14_before_sdid_refit/`: historical code and results already present before the repository reorganization.
- `exploratory_pretrends_2026-11-14/`: discontinued exploratory working material, archived intact during the reorganization. It is not part of the accepted active analysis.

Historical code and logs keep their original paths and contents. They are reference records, not supported current entry points. The shareable active-source ZIP includes this index, not these historical datasets or executable snapshots.
