# Raw-source contract / dataset provenance

**Source-record-first mode:** `run_all.do` always calls `src/build_panel_from_sources.do`. The builder uses only raw external files under `data/raw/`, or downloads them there. It never accepts a pre-existing combined national `.dta`, pre-aggregated FEMA county `.dta`, or sibling repository outputs. Generated source intermediate datasets live under `data/interim/` and `outputs/preprocessing/`.

**IMPORTANT:** The raw input archive is not bundled, so the ZIP alone is not a complete data snapshot. External data may change (e.g. revised FEMA registrations or BLS estimates). Files under `data/raw` are your owned source snapshots. Record/review the SHA-256 manifest after each run and preserve the raw files privately; `.gitignore` prevents accidental publication. The frozen 39-county roster is a **research design reference**, not a substitute for observed source data; the build stops if regenerated FEMA-positive NC treatment does not match it.

`run_all.do` uses only one dataset: the panel generated by `src/build_panel_from_sources.do` during that same run. The 57-month calendar and October 2025 LAUS missingness are deliberate; this calendar is balanced even where an individual outcome is genuinely unobserved.

The original successful script used the independent economicdata.dev LAUS CSV when BLS bulk access returned HTTP 403. That exact documented automatic route is now the DEFAULT: no manual LAUS files are required if the distributor is reachable. Set `H_LAUS_SOURCE_MODE "official"` to request official BLS flat files instead. Neither mode reads any preconstructed `.dta` panel. Distinguish the mirror's transformed BLS data from direct BLS bulk files in citations. Preserve the downloaded CSV and SHA-256 manifest, because data vintages can change. The current mirror's county count, frozen 39 treated NC counties, and Oct 2025 missingness are checked; an unexpected revision stops the build rather than silently selecting counties.

As an alternative to `run_all.do`, you may run only `run_report_only.do` to reformat results from the **last completed run**. This does not reproduce raw data, and the report must retain the original stage-status provenance.

## Source construction vs replication check

1. Source builder creates NOAA, Census, FEMA, BLS extracts and merges strictly by five-digit FIPS and calendar month.
2. Frozen treated roster is checked against fresh FEMA/NOAA classification.
3. SCM weights are trained on Jan 2022–Dec 2023 and Jan–Aug 2024 is validation only.
4. Main panel is saved to `outputs/preprocessing/panels/Helene_NC_ES_preinference_panel.dta`, then copied to `data/input/` **only if the build succeeds**.
5. `outputs/audit/SOURCE_BUILD_AUDIT.txt` and optional `SOURCE_SHA256.txt` document the input lineage. `STAGE_STATUS.csv` and `HELENE_COMPLETE_RESULTS.txt` contain only current-run verified tables (other present tables are labeled stale).
6. A fresh build producing a different treated roster/coverage **fails** until the discrepancy is investigated, instead of editing data to make it match a prior result.
